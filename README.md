# FoodDeliveryApp-ASP.NET-Core-MVC

A Food Delivery Web Application built using ASP.NET Core MVC.

## Features
- User Authentication
- Restaurant & Food Listings
- Add to Cart
- Checkout System
- Order Management
- Responsive UI

## Technologies Used
- ASP.NET Core MVC
- C#
- SQL Server
- Entity Framework Core
- Bootstrap
- HTML/CSS/JavaScript

## Project Purpose
This project was created for learning and academic purposes to understand real-world food delivery application workflows using ASP.NET Core MVC.
